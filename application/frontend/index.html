1. reservation-service (Port 8000)

Usługa FastAPI zarządzająca zasobami i rezerwacjami.

  • • database.py (SQLAlchemy + PostgreSQL / SQLite)
  • • models.py (Resource, Reservation)
  • • main.py (REST API: GET /api/resources, POST /api/reservations, POST /api/reservations/{id}/cancel)

2. user-notification-service (Port 8001)

Usługa FastAPI odpowiedzialna za profile użytkowników i wysyłkę e-mail.

  • • main.py (POST /api/notifications/send-email, GET /api/notifications/logs)
  • • Obsługa profili użytkowników i symulacja wysyłki SMTP

3. Frontend (SVG + Native JS)

Interaktywny interfejs użytkownika podłączony do obu mikroserwisów REST API.

  • • Interaktywna mapa biura w formacie SVG (real-time status)
  • • Hybrydowy klienta API z automatycznym wywołaniem REST i fallbackiem
